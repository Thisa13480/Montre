# La montre Gleason · Prague

Simulateur de montre (fichier unique). La version en ligne est `index.html` ; chaque version est aussi gardée sous son nom (`CLnnn.html`).

https://thisa13480.github.io/Montre/

Fichiers servis à côté de la montre, chargés à la demande puis gardés dans la réserve du navigateur :
- `villages.json` — 135 233 lieux habités du monde (GeoNames, CC BY 4.0), pour la face AIR (CL246) ;
- `fonds/gleason_beige.webp`, `fonds/terre_bleue.webp` — deux fonds de carte du menu « Fond de carte » (CL248), recadrés sur la projection de la montre.
